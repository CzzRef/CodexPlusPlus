# 统一模型 V0.1：本地试用

此功能位于配套开发工作树，面向 macOS arm64。构建组件包不会安装、启动或启用路由。默认 `routingMode` 为 `legacy`；选择启用后，Codex++ 才会写入自己负责的配置并启动配套组件。

## 组件与入口

先构建 Codex++ 启动器，再使用 `scripts/build-unified-components.mjs` 组装组件。脚本的 `--ccw-root` 指向配套 CCW 工作树，`--bun` 指向独立的 Bun 1.4.0，`--launcher` 指向本次编译的启动器，`--output` 必须是新目录。版本固定为 CCW 5.0.6、Bun 1.4.0、Electron 41.10.7；不会升级全局 Bun 或覆盖旧包。

包中包含 `bin/codex-plus-plus`、Bun 网关、Electron 浏览器、许可证及 `components.json`。清单保存四个组件的绝对路径和 SHA-256；移动目录后应重新生成清单。Electron 框架保留包内相对符号链接。

1. 在没有进行中任务时，关闭目标 Codex 窗口并使用包内启动器打开。不要在仍有任务运行时强制重启应用。
2. 打开 Codex++ 设置中的“统一模型”，展开“运行组件”，导入包内 `components.json`。
3. 在旧供应商页面准备 API 配置，然后启用统一路由。重新打开模型选择器，选择官方模型、`cpp/…` API 模型、`cpp-agg/…` 聚合模型或 `chatgpt-web/…` Web 模型。
4. Web 需在“登录 ChatGPT”打开的私有浏览器中完成登录。在“Web 工具连接”填写专用 Tunnel ID 和 Runtime Key，并按页面显示的名称配置 ChatGPT 连接器。密钥保存后从输入框清空；控制接口与进程日志不回传密钥。

这四步是试用流程，需要用户在目标环境中执行；组件构建和离线预览不会代替这些操作。

## 每个任务的行为

“本任务的模型设置”支持各模型声明的推理强度。保存后从下一次模型 HTTP 请求生效，正在执行的请求保持原值。新任务的设置在首轮取得规范任务 ID 后绑定；保存失败会保留草稿以便重试。

聚合成员在一轮内固定。默认依次使用手动选择、本任务上次成员、分组默认及分组策略；选择“按分组的轮转策略”会直接使用策略。分组轮转按 Codex 轮次推进，彼此独立。改成员或分组默认从下一轮生效；已经交付内容或工具后不会自动重放到另一供应商。Web 模型具有固定交互模式，不能用推理强度控件改变它。

API Responses 与 Chat Completions 复用已有协议适配器，并通过指定供应商执行，不切换全局活动供应商。两种压缩入口均使用同一绑定供应商、禁用工具的摘要请求；可读压缩标记在适配前还原，未知加密历史明确拒绝。V0.1 不支持跨后端迁移已有历史或跨后端子代理委派。

## 所有权、恢复与停止

Codex++ 负责官方配置、模型目录及三个组件的生命周期。CCW 使用 Codex++ 数据目录下的专用 `integrations/chatgpt-web` 配置，不导入其他浏览器的 Cookie。托管模式拒绝独立 CCW 的 setup、doctor、route、serve、卸载及更新写入路径。

启用会以恢复日志保存配置基线，仅管理 provider、路由、目录、全局上下文/压缩设置、官方 Voice 路径和本次 Interrupt Hook。原有上下文限制仅应用于官方目录，API/Web 保留各自的模型限制；模型缓存移动到备份目录。原有身份认证和原生 multiagent 设置保留。发现不同来源的配置、目录或恢复冲突会报错，不覆盖冲突。

“停用并恢复”先检查 HTTP、API 与浏览器任务全部结束，再停止所属 tunnel、恢复配置、退出浏览器与网关。忙碌时保留运行状态并提示先完成或取消任务。旧的全局供应商切换及直接重启入口在统一模式中受保护；可使用统一页面的组件控制。浏览器/工具连接不可用时，官方与 API 网关继续运行；“已启动”不代表 ChatGPT 连接器已经验证成功。

## 验收边界

`scripts/smoke-unified-components.mjs` 可对清单启动临时私有网关和真实 Electron，通过本机模拟 API 检查组件独立性、控制鉴权、空闲退出和配置隔离；临时进程及目录会在结束时清理。

[验证记录](../vibe/specs/260908/1421-ccw-unified/verify.md) 区分自动检查、页面预览、实际组件启动与真实账号验收。当前交付仍需在目标账号验证三类模型并发、文件/命令工具、流式取消、首轮设置、压缩、Voice 和停用恢复。仅完成前面的离线检查不能标记这些项目通过。
